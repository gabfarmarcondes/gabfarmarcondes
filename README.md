## Hi, I'm Gabriel 👋

Computer Science undergraduate at the **Federal University of Technology – Paraná (UTFPR)**, graduating in 2027. I build **end-to-end machine learning systems for physiological signals (EEG/BCI)** — from raw signal processing to models served behind an API — backed by hands-on **backend engineering** on a production web platform.

- 🔭 **Currently:** my undergraduate thesis on **cross-dataset generalization for automatic sleep staging**, using unsupervised domain adaptation (DANN, ADAST) across Sleep-EDF, ISRUC-Sleep and HMC
- 💼 **Building:** a production recruitment platform at the Nós Vagas project (NestJS, Prisma, PostgreSQL, React)
- 🎯 **Looking for:** remote internships in machine learning, data science or data engineering
- 🌱 **Learning:** MLOps, deep learning for time series, and clinical AI

### 🚀 Featured Projects

- **[Detecting-Burnout-via-EEG](https://github.com/gabfarmarcondes/Detecting-Burnout-via-EEG)** — End-to-end burnout detection from EEG: few-shot learning evaluated subject-independently (no subject leakage), Grad-CAM explainability, and real-time inference served with FastAPI and Docker.
- **[Motor-Imagery-BCI](https://github.com/gabfarmarcondes/Motor-Imagery-BCI)** — Four-class motor imagery BCI on BCI Competition IV 2a, comparing a classical CSP + LDA pipeline with EEGNet in PyTorch, plus a real-time 2D game demo.
- **[Sleep Stage Classification – ISRUC-Sleep III](https://github.com/gabfarmarcondes/Automatic-Classification-Sleep-Stage-ISRUC-SLEEP_III)** — Single-channel EEG sleep staging: 15 hand-crafted features and a 20-classifier ensemble, benchmarked under subject-wise 10-fold cross-validation (71.8% macro-F1).
